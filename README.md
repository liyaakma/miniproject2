# PSP Student Portal - Mini Project 2

This project is developed for the DFP40443 Full Stack Web Development course.

## Project Description

PSP Student Portal is a web-based student management system developed using the MVC architecture. This Mini Project 2 extends the previous system by adding secure profile picture upload functionality.

## Features

- Student Registration
- Student Login and Logout
- View Student Profile
- Edit Student Profile
- Change Password
- Delete Account
- Upload Profile Picture
- Display Profile Picture

## Profile Picture Upload Security

The profile picture upload function includes the following security validations:

- Only JPG, JPEG and PNG images are allowed.
- Maximum file size is 2MB.
- Uploaded images are renamed using a unique filename.
- The image filename is stored in the database and linked to the logged-in student.
